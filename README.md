# AadharLense

A project based on Aadhaar-related data analysis and machine learning, implemented using Python in a Jupyter Notebook.

## Project Overview

This project contains the analysis and implementation performed on Aadhaar-related data.

The complete work is available in the Jupyter Notebook:

**`AAdhar_project(f).ipynb`**

## Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/51Aditi/AadharLense-.git
```

2. Open the project folder:

```bash
cd AadharLense-
```

3. Install the required Python libraries:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn jupyter
```

4. Start Jupyter Notebook:

```bash
jupyter notebook
```

5. Open:

```text
AAdhar_project(f).ipynb
```

6. Run the notebook cells sequentially.

## Project Purpose

The project was developed to practice data analysis, preprocessing, visualization, and machine learning concepts using Aadhaar-related data.
